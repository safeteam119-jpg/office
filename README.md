# 2026 직원 건강관리 설문조사 (본사용)

본사 직원 대상 건강관리 설문 사이트입니다. 매장용과 내용/디자인은 동일하고, 4번·5번 문항의 세부 항목만 본사에 맞게 다릅니다.
매장용과는 스프레드시트, Apps Script 배포, 깃허브 저장소, 사이트 주소까지 전부 분리되어 있습니다.

## 구조

```
index.html        # 본사용 설문 페이지 (깃허브 Pages로 배포, 저장소 루트)
apps-script/
  Code.gs          # 본사용 구글 스프레드시트에 응답을 적재하는 백엔드 (Apps Script 웹앱)
```

## 매장용과 다른 점

- 4번 문항: "TBM 건강 교육자료" 항목 삭제, "건강프로그램 참여" → "건강프로그램 참여 (금연 캠페인 및 상담 프로그램)"으로 수정
- 5번 문항: "걷기 프로그램 / 그림 컨테스트" 2개 프로그램 구조 → "금연 캠페인 및 상담프로그램 참여" / "참여하지 않음" 2개 보기로 단순화 (참여 시 만족도 하위 질문 노출되는 방식은 매장용과 동일)
- 나머지 1, 2, 3, 6번 문항과 디자인/레이아웃은 매장용과 완전히 동일

## 1) Apps Script 백엔드 배포

1. 본사용 응답을 모을 스프레드시트 열기:
   `https://docs.google.com/spreadsheets/d/1NL1oZeLXY6Vvd_mv7oNYac53UTiFHN3hCCmtGIpxPos/edit`
2. 메뉴 [확장 프로그램] → [Apps Script] 클릭
3. 기본 코드 전체 삭제 후 `apps-script/Code.gs` 내용을 그대로 붙여넣기
4. 저장 (Ctrl+S)
5. 우측 상단 [배포] → [새 배포]
   - 유형 선택(⚙️): **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **전체(Anyone)**  ← 꼭 "전체"로 설정해야 깃허브에서 로그인 없이 호출 가능합니다.
6. [배포] 클릭 → 권한 승인(본인 계정) → 생성된 **웹 앱 URL** 복사

응답은 스프레드시트에 `본사_응답` 탭이 자동 생성되어 쌓입니다.

## 2) 설문 페이지에 백엔드 URL 연결

`index.html` 파일에서 아래 줄을 찾아 1번에서 복사한 웹 앱 URL로 교체합니다.

```js
const SCRIPT_URL = 'YOUR_HQ_APPS_SCRIPT_WEB_APP_URL';
```

## 3) 깃허브 배포 (GitHub Pages)

`https://github.com/safeteam119-jpg/office` 저장소에 이 폴더 내용(`index.html`, `apps-script/`, `README.md`)을 루트로 푸시합니다.

1. 저장소 [Settings] → [Pages] → Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)**
2. 몇 분 후 `https://safeteam119-jpg.github.io/office/` 으로 접속해 테스트 제출 → 스프레드시트에 행이 추가되는지 확인

## 최종 질문 구성 (총 6문항)

1. 올해 진행된 건강관리 활동이 본인의 건강관리 인식 및 실천에 도움이 되었다고 느끼셨습니까? (1~5점 척도)
2. 본인의 건강이 전년도에 비해 개선되었다고 생각하십니까? (예 / 비슷하다 / 악화되었다)
   → "예" 선택 시 하위 질문 노출: 혈당수치 / 혈압수치 / 콜레스테롤수치 / 체중감량 (중복 선택 가능)
3. 올해 진행된 건강관리 활동을 통해 회사가 직원 건강관리에 관심을 갖고 지원하고 있다고 느끼셨습니까? (1~5점 척도)
4. 올해 진행된 건강관리 활동 중 가장 만족하신 활동은 무엇입니까? (중복 선택)
   - 검진 이후 건강관리 (카톡 발송, 전화 상담)
   - 건강프로그램 참여 (금연 캠페인 및 상담 프로그램)
   - 어떠케어 도입을 통한 결과 등록 방식 변경
   - 안전보건 뉴스레터(월간 뉴스레터)
   - 임산부 건강관리 문자
5. 올해 진행된 건강프로그램 중 참여하신 항목 (중복 선택)
   - 금연 캠페인 및 상담프로그램 참여 (선택 시 만족도 하위 질문 노출)
   - 참여하지 않음
6. 추후 참여하고 싶은 건강관리 프로그램은 무엇입니까? (중복 선택)
   1) 걷기 프로그램
   2) 다이어트 및 영양 프로그램
   3) 운동 프로그램
   4) 금주,금연 등 생활습관 프로그램
   5) 스트레스 관리 프로그램
   6) 기타 (직접 입력)
